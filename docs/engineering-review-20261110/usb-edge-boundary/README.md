# USB edge-boundary investigation, 2026-11-10

**Do not move the connectors just to clear the native error.** Moving J_DATA
inward by the required 0.250021 mm creates actual copper-clearance violations.
This investigation is not a boundary waiver, a complete DRC run, or manufacturing
approval. No active-board input, supplier asset, placement or native JSON was edited.

## Reproduce

Run from the repository root with Python 3 (standard library only):

```sh
PYTHONDONTWRITEBYTECODE=1 python docs/engineering-review-20261110/usb-edge-boundary/audit.py
PYTHONDONTWRITEBYTECODE=1 python -m unittest discover -s docs/engineering-review-20261110/usb-edge-boundary -p test_audit.py -v
```

The first command prints JSON without writing anything. Its captured output is
`results.json`. The second command passed **12 tests** on 2026-11-10. Tests cover
face/corner distances, overlap/tangency, duplicate vertices, polygon winding,
unrotated rectangle translation, rotation rejection, malformed/nonfinite inputs,
stale receipts, both native regressions and byte-identical saved results.
No dependency installation, build, native service call or routing is needed.

hashes in `audit.py` and `results.json`; changed inputs fail closed.

## Counterfactual inward move

The script derives the required movement from the actual courtyard overrun,
then translates only J_DATA's SMT copper in memory. It does not edit source or
JSON and does not pretend to simulate a fresh full native build.

| Pair | Current exact gap | After X −0.250021 | Minimum |
| --- | ---: | ---: | ---: |
| TP_BOOT circle to J_DATA polygon land (`pcb_smtpad_63`) | 0.2847692 | 0.0347482 | 0.15 |
| TP_BOOT_GND circle to J_DATA rectangle (`pcb_smtpad_58`) | 0.2848581 | 0.0348371 | 0.15 |

Both moved gaps genuinely fail. These are **SMT lands, not shell tabs**.
The exact calculation uses point-to-segment distances to filled polygon edges,
with an inside test and subtraction of the circular test-pad radius. The input
polygons are assumed simple; repeated/closing vertices are allowed. This is not
a general polygon-topology validator; malformed coordinates, fewer than three
distinct vertices and zero-area polygons are rejected. Only unrotated emitted rectangles are accepted. Rotated rectangles and nonzero
rotation metadata are explicitly rejected; native exact-distance pairs need no
manual rotation. No clearance tolerance is added.
Tests' decimal comparison precision is numerical verification, not a design
clearance allowance. Bounds elsewhere reuse the existing conservative AABB
helper, whose rotated-pill bounds must not be mistaken for exact pair distances.

A broader read-only AABB screen found J_DATA-to-U_DRV top courtyard gap shrinking
from 0.3758751 to 0.1258541, while the already small 0.0343901 gap to C_REF stays
unchanged. R_TEMP_SDA was also flagged by the moved AABB screen, but is **not**
claimed here as an exact-shape violation. J_PD's inward move did not create an
under-0.15 gap in that screen; that alone does not justify changing its mating
position. These ancillary observations are not regenerated by this focused script.

## Supplier body, PCB edge and mating evidence

Current connectors are HRO **TYPE-C-31-M-12 / C165948**, flat right-angle parts.
The [supplier listing](https://www.lcsc.com/product-detail/USB-Type-C_TYPE-C-31-M-12-Female-16P-SMD_C165948.html)
links the [manufacturer drawing](https://datasheet.lcsc.com/datasheet/pdf/9e56b777c022540fcce7c7f67825f55e.pdf?productCode=C165948),
retrieved and visually reviewed on 2026-11-10. It shows a recommended PCB layout,
8.94 mm body width, 7.35 mm body length, 3.26 mm height, Ø0.60 locators on 5.80 mm
spacing and 8.65 mm shell-tab spacing. No explicit allowable PCB-edge recess or
mated cable/overmold envelope was established from it. The online document is
linked evidence, not a locally archived/hash-pinned PDF.

Untouched TSX has courtyard outward extent 5.600021 from origin, locators at
X ±2.899918, shell tabs at X ±4.325112, CAD rotation offset 180° and model-origin
Y −2.7500289. OBJ vertex bounds are X ±4.47, Y −5.3…2.6, Z −0.85…3.251.
Interpreting the declared model origin with the emitted CAD pose puts its outward
mesh extremity at about 14.0000289, nominally flush with the edge. The extra
0.25 mm is therefore consistent with a clearance envelope outside a flush face.
This is a model-transform interpretation, **not an evaluated STEP assembly or
manufacturer-approved tolerance stack**. Raw STEP control-point bounds are not
physical solid bounds. The STEP header identifies SolidWorks 2020 output,
`USB-C_SMD-TYPE-C-31-M-12.step`, dated 2022-07-15.

Moving inward recesses that nominal face by about 0.25 mm. Whether the PCB then
obstructs the plug/overmold cannot be answered from the courtyard check. A passed
boundary check cannot establish mating clearance.

## NEMA14 alignment and plausible next steps

Read-only reference:
[NEMA14 V2 design at d9fcd4208bf7a93743447e1a0ab2c780aa08e304](https://github.com/AnasSarkiz/NEMA14_RP2040_V2/blob/d9fcd4208bf7a93743447e1a0ab2c780aa08e304/docs/v2-design.md).
It uses different USB4145 geometry and a 34.5 mm four-layer board. Its reviewed
locator/rotation and manufacturing work is an example of evidence to obtain,
not approval of C165948 on NEMA11. Current anchors are recorded in repository
`docs/reconstruction-20261108/README.md`.

1. Qualify intentional courtyard overhang using actual body, solder, plug,
   assembly and panel evidence. Only then consider appropriately scoped native
   boundary semantics. Do not use an arbitrary off-board exemption.
2. Recess flat connectors only after mating qualification and neighbor placement
   work. The automatic J_DATA move alone is demonstrably wrong.
3. Enlarging a symmetric board to enclose the existing courtyards requires
   28.500042 mm, exceeding the 28 mm PCB and 28.3 mm assembly-frame requirements.
4. Qualify upright connectors and perform the required all-top design separately.
   Current flat-USB analysis does not demonstrate that final goal.

Missing release evidence: explicit permitted board-edge positioning, evaluated
STEP/footprint registration, connector and PCB tolerances, representative mated
plug/cable clearance, panel rails and assembler process, motor/fastener/insulation
clearance, and qualified upright parts/full all-top placement. All native findings
remain open; routing and fabrication remain blocked.
