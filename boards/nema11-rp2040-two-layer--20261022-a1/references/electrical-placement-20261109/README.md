# Isolated NEMA11 placement study

This directory is a study, not a fabrication release. Main repository files were not edited, committed, pushed or published. Only pose data was changed in this isolated copy. Source and genuine supplier imports match the baseline repository. Native circuit JSON was generated by the unmodified installed CLI, never edited. Routing remains disabled.

## Preferred integrated candidate

- Full pose: `integrated.placement.json` (also `../config/placement.json`).
- Native emitted circuit: `integrated.circuit.json`.
- Native build log: `integrated-native-build.log`; exits 1, with the same two USB outside-board errors.
- Ordinary native placement log: `integrated-native-placement.log`; exits 1, two DRC errors. Its advisory summary also retains three courtyard collisions associated with the DNP encoder and nine suboptimal orientations, as in the baseline.
- Conservative geometry: `integrated.audit.json`; all pads, plated-hole outer copper, courtyard outlines, both layers and DNP copper included. Zero sub-0.15mm copper pairs, 0.160000mm minimum copper gap, 0.389003mm copper-edge minimum, 0.0749997mm minimum pad/courtyard gap to the provisional R2.35 fastener head envelopes. Baseline was 0.044548mm head and 0.361098mm edge.
- Audit does NOT pass because its prior study freeze list includes J_MOTOR; candidate intentionally shifts J_MOTOR by -0.025003mm X. This old anchor was not a user mandate. No check or diagnostic was edited or suppressed.
- Same 99 PCB/source components, 89 fitted components (16 top / 73 bottom), full feature set, no traces or vias. USB poses, encoder origin, motor-hole axes and board dimensions unchanged.
- C_IO33 moved close to its matching MCU supply pin. C_VREG and C_DRV_LOGIC relocate to improve driver supply-pad proximity. Most MCU/clock/flash/decaps move rigidly +0.053998mm Y, preserving their internal relationships. Full exact deltas are in `integrated-pose-deltas.json`.
- The nominal head-margin gain is only 0.030452mm. It is sensitivity evidence, NOT useful tolerance qualification or proof of fastener fit. No actual bolt tolerances were assumed.
- Crystal/flash spacing, buck input loop, driver VM supply placement and physical mounting remain unresolved. Center distances and pad-edge lower bounds are not routed lengths or electrical validation.
- The native PCB PNG was visually reviewed. Dense overlapping silkscreen labels remain; this is not approved assembly artwork.

## Other preserved studies

`baseline.*` preserve the input. `sensitivity-final.*` contain C_IO33 and tiny clearance shifts before two-cap driver integration. Early `candidate-075-native-overlap.placement.json` produced an extra R_DM/C_BUZZER courtyard error; the final sensitivity/integrated candidates remove that new error without suppression. `buck-repack-screening.placement.json` and log are REJECTED: a larger buck rearrangement retained collisions. `flexible-optimization.log` records unsuccessful .15mm screening. Failed numerical optimization does not prove physical infeasibility.

TypeScript and all 23 prebuild regression tests passed. Initial isolated test attempts lacked baseline fixtures; copying the unchanged reference fixtures resolved those file-not-found errors.
