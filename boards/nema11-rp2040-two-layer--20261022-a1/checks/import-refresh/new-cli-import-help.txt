Usage: tsci import [options] <query...>

Search JLCPCB or the tscircuit registry and import a component

Arguments:
  query                     Chip name, part number, or package name

Options:
  --jlcpcb                  Search JLCPCB components
  --lcsc                    Alias for --jlcpcb
  --tscircuit               Search tscircuit registry packages
  --download                Download 3D model assets (.step, .obj) locally
  --exclude-pin-attributes  Skip datasheet pin attributes when importing
  --use-exact-footprint     Keep the exact EasyEDA footprint instead of using a
                            >98% footprinter match
  -h, --help                display help for command
